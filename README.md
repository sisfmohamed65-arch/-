# زهرة حماة — مشروع المتجر

واجهة عربية RTL متجاوبة، سلة مشتريات، نموذج بيانات عميل، وإرسال تفاصيل الطلب إلى رقم واتساب يحدده صاحب المتجر من الإدارة.

## مهم قبل النشر
هذه نسخة بداية للمشروع وليست متجرًا إنتاجيًا مكتملًا بعد. يلزم إعداد Supabase، إنشاء حساب مالك، مراجعة سياسات الصلاحيات، ثم نشر الموقع. لا تضع `service_role` key في المتصفح مطلقًا.

## 1) إنشاء قاعدة البيانات
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql`.
3. من Authentication أنشئ مستخدمًا للمالك بالبريد وكلمة المرور.
4. في `supabase/schema.sql` استبدل `OWNER_EMAIL_HERE` ببريد المالك نفسه، ثم شغّل ملف SQL. هذا يربط صلاحيات الإدارة بحساب المالك المحدد بدل أي حساب مسجل.
6. انسخ Project URL و anon/public key من إعدادات API وضعهما أعلى `app.js` في `SUPABASE_URL` و`SUPABASE_ANON_KEY`.

## 2) تشغيل الموقع
ارفع الملفات إلى GitHub، ثم اربط المستودع مع Netlify. ملف البداية هو `index.html`.
لا تحتاج إلى وضع رقم واتساب في الكود؛ المالك يدخله من لوحة الإدارة بعد تسجيل الدخول.

## 3) فتح الإدارة
اضغط مطولًا على اسم/شعار «زهرة حماة» لمدة تقارب ثانية. تظهر نافذة الدخول. بعد تسجيل الدخول بحساب المالك يمكنك تغيير اسم المتجر ووسائل التواصل (واتساب/ماسنجر/فيسبوك)، وتحديث بريد الإدارة أو كلمة المرور، وإضافة المنتجات وحذفها.

## 4) الطلبات
العميل يضيف المنتجات للسلة، ثم يكتب الاسم ورقم الهاتف وعنوان التوصيل ويختار واتساب أو ماسنجر أو صفحة فيسبوك. واتساب يفتح برسالة مجهزة؛ أما فيسبوك/ماسنجر فيفتح صفحة التواصل وتُنسخ تفاصيل الطلب ليُلصقها العميل يدويًا، لأن فيسبوك لا يسمح بهذا الموقع بإرسال رسالة تلقائية إلى الصفحة. العميل لا يحتاج إلى إنشاء حساب.

## حدود النسخة الحالية
- الصور تُضاف حاليًا كرابط صورة؛ رفع الملفات مباشرة إلى Storage يحتاج إعدادًا إضافيًا.
- الطلب يُرسل عبر واتساب ولا يُحفظ كسجل طلبات داخل لوحة الإدارة حتى الآن.
- تأكد من تعطيل التسجيل العام للمستخدمين في إعدادات Authentication؛ الإدارة محصورة في حساب البريد الذي أضفته إلى جدول admins.
- لا تستخدم بيانات حقيقية قبل إكمال مراجعة الأمان والاختبار.


## تحديث بيانات دخول الإدارة ووسائل التواصل
من لوحة الإدارة يمكن تعديل الإيميل أو كلمة المرور بعد تسجيل الدخول. تحديث الإيميل قد يتطلب تأكيدًا من البريد الجديد. أضف روابط m.me وصفحة فيسبوك أو رقم واتساب، والعميل يختار قناة التواصل المتاحة عند إتمام الطلب.
