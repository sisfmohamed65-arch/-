زهرة حماة — متجر إلكتروني

متجر إلكتروني باللغة العربية، بواجهة RTL متجاوبة مع الهواتف وأجهزة الكمبيوتر.

مميزات المتجر

- عرض المنتجات وتصنيفها والبحث عنها.
- إضافة المنتجات إلى سلة المشتريات.
- إدخال بيانات العميل وعنوان التوصيل.
- إرسال الطلب عبر وسائل التواصل المتاحة.
- لوحة إدارة خاصة بصاحب المتجر.
- إضافة المنتجات وتعديلها وحذفها.
- تعديل اسم المتجر وبيانات التواصل.
- حفظ المنتجات والإعدادات والطلبات باستخدام Firebase.

التقنيات المستخدمة

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore

ملفات المشروع

- "index.html" — الصفحة الرئيسية.
- "styles.css" — تصميم وتنسيق المتجر.
- "app.js" — وظائف المتجر والاتصال بـ Firebase.
- "README.md" — توثيق المشروع.
- "schema.sql" — ملف قديم خاص بـ Supabase، غير مستخدم في إعداد Firebase الحالي.

إعداد Firebase

المشروع يستخدم Firebase، ويجب أن يحتوي ملف "app.js" على إعدادات مشروع Firebase الصحيحة.

الخدمات المستخدمة:

1. Firebase Authentication لتسجيل دخول الإدارة.
2. Cloud Firestore لحفظ المنتجات والإعدادات والطلبات.

قواعد الحماية

يجب ضبط قواعد Cloud Firestore بحيث:

- يستطيع الزوار قراءة المنتجات وإعدادات المتجر.
- يستطيع حساب الإدارة المعتمد فقط تعديل المنتجات والإعدادات.
- يستطيع الزوار إرسال الطلبات وفق شروط التحقق.
- تكون قراءة الطلبات وتعديلها متاحة للإدارة فقط.

تشغيل المشروع

ملف البداية هو "index.html".

يمكن تشغيل المشروع محليًا أو ربط مستودع GitHub بخدمة استضافة عند الاستعداد للنشر.

ملاحظات

- لا تضع كلمات المرور أو المفاتيح السرية داخل المستودع.
- لا تشارك بيانات دخول الإدارة.
- يجب اختبار تسجيل الدخول والمنتجات والطلبات قبل استخدام المتجر فعليًا.
- لا يزال ملف "schema.sql" محفوظًا لأغراض الرجوع إلى النسخة القديمة.
